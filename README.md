# Aplicativo de Controle Financeiro

Este é um aplicativo de controle financeiro desenvolvido com Python (Flask), HTML e CSS. O objetivo é permitir o gerenciamento eficiente das suas finanças pessoais, oferecendo recursos para adicionar, editar e visualizar suas despesas e receitas, além de gerar gráficos para acompanhar seu desempenho financeiro ao longo do tempo.

## Funcionalidades

- **Controle de Despesas e Receitas**: Adicione facilmente suas despesas e receitas em diferentes categorias.
- **Gráficos Interativos**: Visualize seus dados financeiros por meio de gráficos que mostram a distribuição de suas despesas.
- **Relatórios**: Gere relatórios financeiros para visualizar um resumo das suas finanças em diferentes períodos.

## Tecnologias Utilizadas

- **Backend**: Python com Flask
- **Frontend**: HTML, CSS (estilo moderno e responsivo)
- **Banco de Dados**: SQLite
- **Gráficos**: Gráficos simples utilizando bibliotecas de visualização no frontend (ex: Chart.js ou outra, se necessário)
- **Autenticação**: Sistema de login e cadastro usando sessões no Flask
